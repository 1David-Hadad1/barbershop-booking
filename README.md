# מספרה — מערכת תורים למספרה (פרויקט דמו)

אתר הזמנת תורים לספר לדוגמה: לקוחות בוחרים יום ושעה ונרשמים לתור, ובעל העסק
מנהל את כל התורים דרך פאנל אדמין מוגן בהתחברות.

## הרצה מקומית

```bash
npm install
npm run dev
```

לפני שהזמנת תורים/כניסת האדמין יעבדו בפועל צריך לחבר את הפרויקט ל-Supabase (ראו למטה).

## חיבור ל-Supabase (חינמי, בלי כרטיס אשראי)

1. היכנסו ל-[supabase.com](https://supabase.com) והירשמו (למשל עם חשבון GitHub).
2. לחצו **New project**, תנו שם (למשל `barbershop-booking`), בחרו סיסמת מסד נתונים ואיזור (Region) קרוב, ולחצו **Create**.
3. בתפריט הצד: **SQL Editor** → **New query**. העתיקו לשם את כל התוכן של הקובץ [`supabase/schema.sql`](supabase/schema.sql) בפרויקט הזה, ולחצו **Run**. זה יוצר את טבלת `appointments` ואת כל הרשאות האבטחה (RLS).
4. בתפריט הצד: **Authentication** → **Users** → **Add user**. הזינו אימייל וסיסמה עבור בעל העסק (את הפרטים האלה תשתמשו כדי להתחבר בעמוד `/admin/login`).
5. בתפריט הצד: **Project Settings** → **API**. שם תמצאו:
   - **Project URL**
   - **anon public key**
6. צרו קובץ `.env` בתיקיית הפרויקט (העתיקו מ-`.env.example`) והדביקו את שני הערכים:
   ```
   VITE_SUPABASE_URL=...
   VITE_SUPABASE_ANON_KEY=...
   ```
7. הפעילו מחדש את `npm run dev`.

**חשוב**: אל תעבירו את ה-`.env` או את הסיסמה של המסד לאף אחד, ואל תעלו את `.env` ל-git (הוא כבר מוגדר ב-`.gitignore`).

**הערה**: פרויקט Supabase בטיר החינמי "נרדם" (pauses) אחרי כשבוע ללא שימוש. אם האתר לא זמין לפני פגישה — כנסו לדשבורד ב-supabase.com ולחצו להעיר את הפרויקט, זה לוקח כמה שניות.
